# 00 — Project Overview

## 1. Problem Statement

Given a single image of a human face, decide whether it is:

- **Real** — a photograph of an actual person, or
- **Fake** — an image synthesized by a generative model (here, **StyleGAN**).

This is a **binary image classification** problem. The model outputs one number: the
probability that the image is fake.

## 2. What is a "Deepfake"?

"Deepfake" = *deep learning* + *fake*. It refers to any media (image, video, audio) that has
been generated or manipulated by a deep neural network so it looks real.

There are two broad families:

| Type | Example | What happens |
|------|---------|--------------|
| **Face manipulation** | Face swap, lip-sync (FaceForensics++) | A real video is edited — one face is replaced by another |
| **Entire face synthesis** | StyleGAN, "thispersondoesnotexist.com" | A brand-new face that never existed is generated from random noise |

This project works on the **second type** — fully synthetic faces.

### 2.1 How StyleGAN makes a fake face (short version)

A **GAN (Generative Adversarial Network)** has two networks that compete:

1. **Generator (G)** — takes a random noise vector `z` and produces an image.
2. **Discriminator (D)** — looks at an image and says "real" or "fake".

They are trained together: G tries to fool D, D tries not to be fooled. Over time G becomes
very good at producing realistic images.

**StyleGAN** (Karras et al., NVIDIA, 2019) improves the generator by:
- mapping `z` through a *mapping network* into an intermediate "style" space `w`,
- injecting that style at every resolution layer (coarse → pose/shape, fine → skin/hair texture),
- adding per-pixel noise for stochastic detail (freckles, hair strands).

### 2.2 Why fakes are still detectable

Even very realistic GAN faces leave **artifacts** that a CNN can learn to spot:

- **Up-sampling artifacts** — the generator builds the image by repeatedly up-sampling,
  leaving periodic patterns in the high-frequency spectrum (invisible to humans).
- **Asymmetries** — mismatched earrings, different eye reflections, uneven glasses.
- **Hair / background boundaries** — blurry or "melting" texture where hair meets background.
- **Teeth and ears** — often malformed or smeared.
- **Background** — warped, nonsensical objects.

Our classifier never gets told about these explicitly — it *learns* which pixel patterns
separate the two classes. Grad-CAM (Module 6) will later show us *where* it looks.

## 4. Why Transfer Learning?

Training a CNN from scratch needs a lot of data and GPU time. Instead we use networks
**pretrained on ImageNet** (1.2M images, 1000 classes). Their early layers have already
learned general features — edges, textures, colour blobs — which are useful for almost any
vision task. We only need to **adapt** (fine-tune) the later layers to our new task.

Benefits:
- converges in a few epochs (fits within Colab free-tier limits),
- much higher accuracy with less data,
- less overfitting.

## 5. Dataset Choice

**140k Real and Fake Faces** (Kaggle, user *xhlulu*):

- 70,000 real faces from **FFHQ** (Flickr-Faces-HQ)
- 70,000 fake faces generated by **StyleGAN**
- All resized to 256×256
- Pre-split: train 100k / valid 20k / test 20k, perfectly balanced 50/50

Balanced classes mean **accuracy is a meaningful metric** (no class dominates), but we will
still report precision/recall/F1/AUC for completeness.
