# Deepfake Detection — Real vs StyleGAN Faces

A binary image classifier that tells **real face photos** apart from **StyleGAN-generated fake faces**.
The project fine-tunes pretrained CNNs (EfficientNet-B0 and ResNet-18), explains their predictions
with **Grad-CAM** heatmaps, and includes a simple **Streamlit** demo app.

> Course project — Machine Learning (Semester 5)

## Overview

| Component        | Choice                                                         |
|------------------|----------------------------------------------------------------|
| Dataset          | 140k Real and Fake Faces (Kaggle) — 70k real, 70k fake, pre-split |
| Primary model    | EfficientNet-B0 (pretrained on ImageNet, fine-tuned)           |
| Comparison model | ResNet-18 (frozen vs unfrozen ablation)                        |
| Explainability   | Grad-CAM heatmaps on the final conv layer                      |
| Deployment       | Streamlit app — upload → prediction + confidence + heatmap     |
| Compute          | Google Colab (free-tier GPU)                                   |

## Tech Stack

Python · PyTorch · torchvision · OpenCV · scikit-learn · pytorch-grad-cam · Streamlit

## Dataset

**140k Real and Fake Faces** — https://www.kaggle.com/datasets/xhlulu/140k-real-and-fake-faces

- Real faces: from the Flickr-Faces-HQ (FFHQ) dataset collected by Nvidia
- Fake faces: generated by StyleGAN
- Already split into `train` / `valid` / `test`, each with `real/` and `fake/` sub-folders

The dataset is **not** stored in this repository (too large). Download it and place it so it looks like:

```
data/
├── train/{real,fake}/
├── valid/{real,fake}/
└── test/{real,fake}/
```
